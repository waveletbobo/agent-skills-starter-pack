# 任务合同与验收清单（派活时复制）

## 派活模板（发给 AI 时填空）

任务：{{一句话说清要什么}}
按 AGENTS.md 第 0 节和第 2 节来。先出计划：改哪几个文件、预计加多少行、怎么验证。
输出预算：回复只给计划/代码/证据，不写解释长文；预计行数超了先停下报数。

## 验收三信号（完工时逐个打勾）

- [ ] 先出计划：动手前给了文件清单和行数预算
- [ ] 不碰禁区：diff 里没有第 0 节的东西，没有顺手重构
- [ ] 完工给证据：测试输出 / 日志 / 演示，三选一真实给出

## 信号没过时怎么迭代

哪个信号没过，就把那次 diff 里的问题翻译成一条新规矩补进 AGENTS.md 对应节：
「现象 → 规则 → 放第几节」。一次只补一条，补完用下一个小任务验证。
规矩只加不堆：同一节超过 15 条时，先删已内化或重复的再加新的。
